# 初中函数绘图（SwiftUI）

一个使用 SwiftUI 和 Canvas 实现的初中数学函数绘图核心视图，适用于 iOS 16 及以上版本。

## 已实现功能

- 绘制自定义函数表达式，支持 `y=2x+1`、`y=x^2-4`、`y=1/x` 等写法
- 表达式解析和实时校验；支持 x、括号、加减乘除、幂运算及 `sin`、`cos`、`tan`、`abs`、`sqrt`、`exp`、`ln`、`log`
- 常见函数示例：一次函数、正比例函数、二次函数、反比例函数
- 对比曲线开关：可叠加显示 y=x、y=-x、y=x²-4、y=2/x、y=|x|，并使用不同颜色
- 双指捏合缩放坐标系，曲线与网格同步缩放
- 拖动平移绘图区，一键重置视图
- 自适应网格间距和坐标刻度
- 关键点辅助：数值方法检测 x 轴交点、计算 y 轴交点，并尝试识别标准二次函数顶点
- 函数值表：自定义 x 起点、终点和步长
- 学习面板：一次函数、反比例函数、二次函数的基础说明与示例

## 运行

1. 在 Xcode 中新建 iOS App 项目，界面选择 SwiftUI，最低系统版本设为 iOS 16。
2. 将 `ContentView.swift` 添加到项目中，替换模板中的同名视图。
3. 在 iOS 模拟器或设备上运行。

> 此仓库目前提供应用核心视图源码，并非完整的 `.xcodeproj` 工程。Git 仓库中的 `funDraw` 目录当前是子模块引用；如需直接克隆并编译，请先确认子模块地址和初始化状态。
